<p align="center"><a href="README.md">English version</a></p>

## Задача

Исходные данные — полигональная модель обнажения, полученная фотограмметрией
или лазерным сканированием. Аддон снимает с неё замеры трещин, вычисляет
ориентировку и метрические характеристики каждого замера, строит распределения
и выгружает результат в CSV.

Модель должна быть ориентирована. Расхождение с истинным севером задаётся
поправкой азимута и учитывается при расчёте (порядок работы, шаг 4).

Аддон поддерживает следующие замеры:

- азимут и угол падения плоскости трещины;
- расстояние между трещинами одной системы;
- протяжённость трещины по поверхности;
- площадь контура в плоскости замера;
- группировку замеров по системам через коды и плотность полюсов на
  стереограмме.

## Типы замеров и вычисляемые величины

| Тип | Точек | Вычисляется |
|---|---|---|
| `LINEAR` | 2 | Расстояние между точками. Азимут и погружение линии, азимут и падение перпендикулярной ей плоскости, поправленный азимут. Приращения `dx`, `dy`, `dz` и горизонтальная проекция. |
| `PLANE` | 3 | Азимут падения, угол падения, поправленный азимут. Площадь треугольника. Угол при средней точке. Признак вырожденности, если точки лежат на одной прямой или совпадают. |
| `POLYLINE` | 3 и более, контур замкнут | То же, что `PLANE`, но плоскость подбирается по всем точкам методом наименьших квадратов. Дополнительно среднеквадратичное отклонение точек от подобранной плоскости, абсолютное и относительное. |
| `TRACE` | 2 и более, контур открыт | Сумма длин сегментов. Число сегментов, средняя, минимальная и максимальная длина сегмента. Прямое расстояние между концами и отношение суммы к нему. Азимут и погружение прямой между концами. |

Поправка азимута применяется к азимутам всех типов. Исходный азимут сохраняется
и выгружается отдельным столбцом.

## Инструменты

Три инструмента находятся в тулбаре 3D-вида после штатной линейки Blender.

| Иконка | Инструмент | Действие |
|---|---|---|
| ![](docs/icons/scientiajoints.measure.png) | Scientia Measure | Протяжка по пустому месту создаёт замер `LINEAR`. Протяжка за середину отрезка добавляет третью точку и переводит замер в `PLANE`. Протяжка за точку перемещает её. |
| ![](docs/icons/scientiajoints.polygon_measure.png) | Scientia Polygon Plane | Клики задают точки замкнутого контура, замер сохраняется как `POLYLINE`. Минимум три точки. |
| ![](docs/icons/scientiajoints.trace_measure.png) | Scientia Trace | Клики задают точки открытой полилинии, замер сохраняется как `TRACE`. Минимум две точки. |

У полигона и трассы одинаковое управление. `ПКМ`, `Enter` или `Space` завершают
замер. `Backspace`, `X` или `Del` убирают последнюю точку. `Esc` отменяет.
Полигон дополнительно замыкается кликом по первой точке. Трасса не замыкается.

Во всех трёх инструментах `Ctrl` переключает привязку к видимой геометрии.
Состояние привязки по умолчанию задаётся в заголовке инструмента.

## Источники замеров

Аддон читает замеры из двух источников: инструментов аддона, которые хранят
замеры в свойствах сцены `.blend`, и аннотаций штатной линейки Blender из слоя
`RulerData3D`. Замеры из обоих источников обрабатываются одинаково.

Точные дубликаты объединяются. Замеры, координаты которых совпадают до третьего
знака, сохраняются оба и выносятся в отчёт диагностики. Для модели в метрах это
один миллиметр. Отличить случайную копию от двух близких трещин может только
оператор.

## Установка

На каждую версию публикуются два архива. Они устанавливают `matplotlib` и
`mplstereonet` разными способами.

### Extension

`ScientiaJoints-<версия>-extension.zip` содержит wheel-файлы внутри архива.
Blender распаковывает их сам, без pip, без обращения к индексу пакетов и без
сети. Путь установки короткий.

1. Скачайте extension-архив. Архив `Source code` с GitHub не является
   устанавливаемым пакетом.
2. Перетащите ZIP в окно Blender или выберите
   `Edit > Preferences > Get Extensions > Install from Disk`.

### Legacy add-on

`ScientiaJoints-<версия>.zip` устанавливается через
`Edit > Preferences > Add-ons > Install from Disk`. Пакеты для графиков аддон
устанавливает сам: сначала из вложенных wheel-файлов, при неудаче с PyPI.
Установка идёт на отдельном потоке, Blender не блокируется. Ход и результат
выводятся в панель аддона. Неудачная автоматическая попытка повторяется не чаще
раза в сутки. Переменная окружения `SCIENTIAJOINTS_NO_AUTO_INSTALL` отключает
автоматическую попытку.

Архив всегда содержит `ScientiaJoints/__init__.py`. Это имя каталога требует
Blender, и оно не зависит от имени самого ZIP. Архив, корневой каталог которого
называется иначе, установить нельзя.

Минимальная версия Blender — 5.0.0. Требуется `mplstereonet` 0.6.3 или новее.
В 0.6.2 и раньше используется `np.float`, удалённый в numpy 1.24, из-за чего
контуры плотности на стереограмме не строятся.

### Если графики не появились

Иконка `i` в заголовке панели открывает отчёт диагностики. Отчёт называет
причину и действие. Наблюдаемые причины:

- пакеты не установлены; панель показывает отсутствующие и кнопку установки;
- ограничение длины пути в Windows 260 символов. `matplotlib` читает свои
  data-файлы при импорте. За этой границей файлы существуют, но не открываются,
  импорт завершается `FileNotFoundError`. Отчёт показывает остаток символов для
  каждого каталога установки;
- вторая копия numpy рядом со встроенной в Blender даёт ошибки бинарной
  совместимости в `matplotlib`;
- сеть, блокирующая или инспектирующая HTTPS. Отчёт различает ошибку
  сертификата, отказ прокси, таймаут и недоступный индекс.

Первые три причины к extension-архиву не относятся. Пакеты лежат внутри него,
путь установки короткий, numpy в интерпретатор Blender не устанавливается.

## Порядок работы

1. Загрузите модель обнажения.
2. Разметьте трещины инструментами из тулбара.
3. Присвойте замерам коды в разделе `Measurement Info`. Код получает цвет и
   переключатель видимости, что позволяет отображать системы трещин по одной.
4. Задайте поправку азимута в разделе `Azimuth Correction`, если модель
   развёрнута относительно истинного севера. `Real` — истинный азимут ориентира,
   `Model` — азимут того же ориентира в модели.
5. Откройте графики кнопками в верхней части панели: гистограмма длин рёбер,
   стереограмма плотности полюсов, гистограмма длин трасс. Рядом с каждой
   кнопкой находится переключатель автообновления. Одновременно работает один.
6. Выгрузите результат в разделе `Export`. CSV содержит вычисленные величины,
   TXT — исходные координаты. Файл `.blend` должен быть сохранён: путь выгрузки
   строится относительно него.

Длины трасс выводятся отдельной гистограммой. Длина трассы — сумма длин
сегментов, длина ребра — расстояние между двумя точками. Это разные величины,
и одно распределение их не описывает.

### Отображение модели

`Chart Appearance > Blender View > Rock Inspection` переводит все 3D-виды в
режим Rendered и задаёт освещение: направленный источник с превышением 22°,
угловым размером 0.5° и нулевым зеркальным вкладом, матовый материал, яркость
фона 1.5. Направленный источник даёт тени в трещинах и уступах, фон задаёт
общую яркость поверхности.

Повторное нажатие восстанавливает режим отображения, фон, материал, камеру,
параметры цветокоррекции и рендера и удаляет добавленный источник.

Замечание. Параметры материала применяются к материалу с именем `material0`.
Материалы объектов сцены при этом не изменяются.

## Производительность

Замеры получены на синтетической сцене со стабами GPU и `blf`, минимум из пяти
перерисовок:

| Замеров | Время перерисовки | Вызовов отрисовки |
|---|---|---|
| 500 | 18 мс | 9 |
| 2000 | 23 мс | 9 |
| 10000 | 31 мс | 9 |

До оптимизации 500 замеров занимали 163 мс при 5452 вызовах отрисовки, 2000 —
644 мс при 21823 вызовах. Сцена на 10000 замеров не укладывалась в двухминутный
лимит теста.

Геометрия трёхмерного прохода строится в мировых координатах и кэшируется.
Вращение и панорамирование её не пересчитывают. Экранные элементы, точки и
подписи, пересобираются каждый кадр. Их количество ограничено бюджетом
`Overlay Style > Viewport Budget`: 2000 точек и 200 подписей по умолчанию.
Отрисовываются ближайшие к центру вида, активный замер и замер под курсором.

## Сборка релиза

Требуется Python 3.10 или новее и полная копия репозитория. Blender нужен
только для проверки собранного архива.

1. Задайте версию:

   ```powershell
   python tools\version.py 3.4.2
   ```

   Версия хранится в `blender_manifest.toml`. Blender читает `bl_info` из
   `__init__.py` через `ast.literal_eval` до импорта аддона, поэтому эта копия
   не вычисляется. Команда записывает оба файла. `tools\build_release.py`
   отказывается собирать копию, в которой значения разошлись. Без аргумента
   команда выводит текущую версию.

2. Внесите запись в `CHANGELOG.md`.

3. Загрузите wheel-файлы. Запускайте интерпретатором Blender, чтобы теги
   совпали с целевой версией:

   ```powershell
   & 'E:\SteamLibrary\steamapps\common\Blender\5.2\python\bin\python.exe' tools\fetch_wheels.py --platform win_amd64 --python-version 3.13
   ```

   Ключ `--all-platforms` собирает набор для Windows, Linux и macOS. Каталог
   `wheels/` не коммитится и пересобирается для каждого релиза.

4. Запустите тесты из корня репозитория:

   ```powershell
   python -m unittest discover -s tests -v
   ```

5. Соберите архивы:

   ```powershell
   python tools\build_release.py
   ```

   Команда записывает `dist/ScientiaJoints-<версия>.zip` и
   `dist/ScientiaJoints-<версия>-extension.zip`, проверяет структуру пакета,
   синтаксис Python, наличие требуемых символов в модулях, согласованность
   манифеста с вложенными wheel-файлами и выводит SHA-256. Ключи
   `--format legacy` и `--format extension` собирают один архив.

6. Проверьте extension-архив средствами Blender:

   ```powershell
   & 'E:\SteamLibrary\steamapps\common\Blender\blender.exe' --command extension validate "dist\ScientiaJoints-$(python tools\version.py)-extension.zip"
   ```

7. Установите оба архива в чистый профиль. Переменная
   `BLENDER_USER_RESOURCES` должна указывать на пустой каталог с коротким путём.

Legacy-архив содержит wheel numpy. `pip --target` разрешает зависимости, не
учитывая уже установленные пакеты, и без этого wheel офлайн-установка
завершается ошибкой. Extension-архив numpy не содержит: Blender поставляет свой,
вторая копия даёт ошибки бинарной совместимости.

### Артворк

Иконки инструментов Blender загружает из `icons/*.dat`. Формат содержит список
треугольников на холсте 255×255, не растровое изображение. Артворк задан
вектором в `tools/build_tool_icons.py`:

```powershell
python tools\build_tool_icons.py --preview preview.png
python tools\build_tool_icons.py --png --png-size 1024
python tools\build_logo.py --size 512
```

Файлы `.dat` закоммичены, обычная сборка их не пересоздаёт. Скрипт нужно
запустить после изменения кода отрисовки. Ключ `--png` записывает PNG с
прозрачным фоном, `tools/build_logo.py` — логотип аддона.
`tests/test_tool_icons.py` проверяет, что закоммиченные `.dat` совпадают с
результатом генератора, что формат корректен и что инструменты не используют
встроенную иконку линейки вместо собственной.
